📌 Project Overview

This project is an HTML-based wireframe for my personal portfolio website.
It represents the basic structure and layout of the site without final styling or functionality.
The purpose of this wireframe is to plan the visual structure before applying CSS and JavaScript.

🧩 What This Wireframe Includes

✔ Header with navigation
✔ Hero / Introduction section
✔ About Me block
✔ Skills section
✔ Project gallery layout
✔ Education and certification blocks
✔ Contact information section
✔ Footer navigation

This wireframe helps visualize how the final website will look once styling is added.

🛠️ Technology Used

HTML5 (only structure, no CSS framework)

Placeholder images

Text blocks for planning content
